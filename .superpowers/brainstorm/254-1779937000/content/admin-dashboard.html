功能清单汇总

模块A：商品管理
  • 编辑单价（输入框直接修改）
  • 上架/下架切换
  • 新增商品（弹窗表单）
  • 分类管理（增删分类）
  • 搜索 + 分类 + 状态筛选
模块B：订单管理
  • 货单列表：单号/收货人/电话/地址/状态
  • 展开详情：商品明细 + 数量
  • 后台定价：为每行商品设单价，自动计算小计和总价
  • 导出功能：单条导出 + 批量导出Excel
  • 搜索 + 状态筛选
